## Complete mutation workflow

Create background/vehicle and three further points/paths; edit middle controls; select without model changes; move shared endpoint while retaining controls; insert and default new links; reorder directed adjacency; delete a middle point and default reconnection. After every step, recheck all paths and validate the complete model.

Strict point ordering, n−1 valid directed links, unique identities, finite geometry and reference preservation hold. Selection attaches to retained identities and safely clears removed ones. States, metadata and editor-state separation stay intact.

## Defensive checks
