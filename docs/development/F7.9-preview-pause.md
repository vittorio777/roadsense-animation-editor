# F7.9 Preview Pause

**Status:** Completed in the original MVP development record.

## Requirement and scope

Add Pause to the existing transport/clock and hold exact last committed time, resuming without counting paused wall-clock duration.

## Design and implementation

Same enabled button switches Play preview/Pause preview while retaining node/focus/width. stopPreviewPlayback changes only temporary state; cleanup cancels pending frame and store guards stale callbacks. Resume establishes a new first-frame baseline. Paused seek remains paused. Preserve existing end-stop/replay.
