# F6.3 — Save Project

**Status:** Completed in the original MVP development record.

## Requirement and scope

Download current project JSON through the toolbar using existing serialization, with safe names, resource cleanup and no state mutation.

## Design and implementation

The adapter returns downloaded/filename, invalid/errors or failed/message. Serialize project only; create application/json; charset=utf-8 Blob, object URL and temporary anchor, trigger once and clean both resources in success/error paths. Filename trims animationId, replaces forbidden/control/path characters with hyphens, collapses whitespace/hyphens, removes edge space/dot/hyphen, caps base at 100 characters and falls back to animation-project. Local aria-live feedback does not change data.

## Acceptance criteria

1. **AC1:** Named focusable Save command fits existing toolbar identity/height.
2. **AC2:** Send only state.project, excluding store/actions/editor data.
3. **AC3:** Download bytes exactly match shared serializer output.
4. **AC4:** Trigger one UTF-8 JSON Blob download with .json extension.
5. **AC5:** Safe deterministic filename preserves original identity/JSON, including Unicode.
6. **AC6:** Remove anchor/revoke created URL on success or exception.
7. **AC7:** Invalid data creates no download resources and gives failure feedback.
8. **AC8:** Browser failures are caught, clean available resources and preserve state.
9. **AC9:** Report download started with actual filename through local aria-live feedback.
10. **AC10:** Success/failure preserves all store references and editor state.
11. **AC11:** Repeated saves independently trigger/clean once with identical bytes/name.
12. **AC12:** Desktop matrix/fallback keeps toolbar text/commands usable.
13. **AC13:** Real nonempty downloaded file parses, matches serializer and validates.
14. **AC14:** No Load/parser/replacement expansion yet.
15. **AC15:** Targeted/full checks pass without dependency or design changes.

## Verification and acceptance

- Focused verification: 4 files/27 tests; the full suite passed 53 files / 370 tests, strict type checking, production build and diff checks passed.
- Browser background+original car downloaded untitled-animation.json, 1633 bytes, 1 vehicle/point, no time/selection.
- Toolbar showed Download started; console no errors.
- Three desktop sizes and fallback passed.
- Human acceptance: 2026-10-01 covered download, repeat and preservation; advisory remained.
