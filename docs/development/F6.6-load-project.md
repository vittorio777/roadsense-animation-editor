# F6.6 — Load Project

**Status:** Completed in the original MVP development record.

## Requirement and scope

Compose read→parse→validate→resolve, then replace project and reset core editor state only after complete success. Failures cannot partially replace current work.

## Design and implementation

prepareAnimationProjectFile returns ready/project/assets or classified failure and does not touch store. Dependency interfaces verify short-circuit ordering. One loadProject set replaces project, sets time 0 and all selection IDsnull; existing setProject remains internal. Toolbar uses hidden single JSON input, clears its value for same-file repeats, disables Load during read, and shares local feedback with Save. Preserve parsed data without IDs/defaults/normalization.

## Acceptance criteria

1. **AC1:** Named Load beside Save fits toolbar identity/layout.
2. **AC2:** Native hidden single-file JSON picker; cancel leaves state unchanged.
3. **AC3:** Clear input value so same file runs again.
4. **AC4:** Ordered pipeline short-circuits failure before dependent stages.
5. **AC5:** Ready contains exact validated parsed project and resolved assets.
6. **AC6:** Apply one atomic replacement, not per-field merging.
7. **AC7:** Reset time 0 and all four selection IDs while retaining loaded data.
8. **AC8:** Preserve IDs/numbers/controls/states/array order.
9. **AC9:** Accessible local Loaded:<filename> feedback.
10. **AC10:** Pending read disables Load with processing text; editor/Save remain stable.
11. **AC11:** Any stage failure preserves complete store/project/time/selection references.
12. **AC12:** Only generic accessible failure feedback here; detailed errors belong to F6.7.
13. **AC13:** Post-load Save uses the new project and existing cleanup/name semantics.
14. **AC14:** Three desktop sizes/fallback keep commands readable and separate.
15. **AC15:** Real downloaded file restores scene/timeline, clears selection/time and shows filename.
16. **AC16:** No detailed error UI/migration/round-trip gate/extra persistence yet.
17. **AC17:** Focused tests and the full suite pass.
