# F7.7 Preview Seek

**Status:** Completed in the original MVP development record.

## Requirement and scope

Render every vehicle's composed position/direction when any existing time entry changes. Seeking alone must not author data.

## Design and implementation

Scene maps composed state by stable ID to original asset/handlers. Centered group uses composed x/y/rotation; source paths/points/guides stay in authoring coordinates. No stale previous-point fallback on failure. Drag from visible pose commits through existing current-time rule. Object-only properties now uses composed coordinates so one-axis editing does not restore the other axis to the previous point; selected-point edits remain source-specific.

2. **AC2:** Timeline mapped/snapped seek refreshes scene/playhead/readout.
3. **AC3:** Curved quarter/mid/arbitrary poses match shared mathematics.
4. **AC4:** Body/outline rotate together while authoring overlays do not.

12. **AC12:** No light/icon/audio visuals yet.
