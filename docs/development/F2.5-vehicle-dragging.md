# F2.5 — Vehicle Dragging

**Status:** Completed; human acceptance passed.

## Requirement and design

Drag the vehicle and commit logical coordinates to its existing zero-time movement point. During drag, position is temporary display state; drag end commits the clamped result.

The center is bounded by half the registry asset size on each scene edge. For the original 120 × 72 car in a 1600 × 900 scene, bounds were X 60–1540 and Y 36–864. Properties editing and additional points were outside this feature.

## Acceptance criteria

1. **AC1:** Vehicle and outline follow dragging together without drift or layout jumps.
2. **AC2:** Commit logical scene coordinates rather than scaled screen pixels.
3. **AC3:** Repeated dragging updates only coordinates of the existing point, preserving ID/time and point count.
4. **AC4:** Dragging under scale and later resize preserve the same saved location and outline alignment.
5. **AC5:** Keep the complete vehicle inside every edge/corner using registry-size bounds.
6. **AC6:** Drag start selects the object and clears subordinate selection; release retains it.
7. **AC7:** Preserve IDs, assets, paths, state tracks, background, dimensions and time.
8. **AC8:** Click without displacement selects without changing the project.
9. **AC9:** Properties remains a read-only summary.
10. **AC10:** No additional movement/state/path data, rotation edits or second vehicle.
11. **AC11:** Clamp, store, drag, scale and selection tests plus regressions, strict checking and build pass.

## Implementation and verification

clampVehiclePosition centralizes bounds. updateVehiclePosition immutably updates the existing first point and is a no-op for missing IDs or unchanged positions. A draggable Konva Group contains the image and outline; drag start selects, drag move clamps group coordinates, and drag end commits.

The original run passed 12 files / 49 tests, strict checking and build. Edge/corner bounds, reference no-ops, data isolation and logical coordinates under Stage scale 0.5 passed. Browser review at 1280 × 720 confirmed dragging, retained instance selection and right/bottom bounds. Console warnings/errors were absent; dependencies/design documents were unchanged. The 558.64 kB chunk-size advisory remained.

Human acceptance:  covered movement/outline synchronization, persisted position, bounds and read-only properties. **Original commit message:** `feat: add vehicle dragging`.
