# F5.9 — State Interval Editing

**Status:** Completed in the original MVP development record.

## Requirement and scope

Select, move, resize and delete existing derived intervals without duplicating saved state. Right-clipped/open intervals must keep their real end semantics.

## Design and implementation

Local interval selection is separate from global editor identity at this stage. Finite body drag needs≥4 px and preserves duration; resize handles act directly. Preview-only until release; Escape cancels. Delete command/Delete/Backspace supports finite/clipped/open spans. Edit pure boundary mutation validates source/occupancy, retains opposite indicator side and normalizes keys. Clipped/open spans allow left resize and deletion; display clipping does not create an end keyframe.

## Acceptance criteria

1. **AC1:** Click gives accessible local selection/controls without project/time/global-selection change.
2. **AC2:** Finite move threshold shows snapped duration-preserving preview without writes.
3. **AC3:** Valid release moves and restores original inactive range, normalizing keyframes.
4. **AC4:** Edge clamp shifts the whole span without shrinking duration.
5. **AC5:** Left resize changes real start only, retaining real/open end.
6. **AC6:** Visible finite right resize changes end only and rejects zero/reversed/out-of-range.
7. **AC7:** Command/keyboard deletion inactivates full real span, preserves outside state and clears local selection.
8. **AC8:** Indicator mutation preserves other side and all transitions.
9. **AC9:** Same-lane positive overlap atomically rejects with feedback; adjacent spans merge.
10. **AC10:** Right-clipped/open intervals disable body and right-edge dragging; clipping at 10 seconds does not create an end keyframe.
11. **AC11:** Escape/invalid source/time/range/owner/lane produces no partial writes/errors.
12. **AC12:** Only target owner/track changes; preserve unrelated references/time/global selection.
13. **AC13:** Strict unique ordered times, remove same-value redundancy and retain usable IDs.
14. **AC14:** Keep creation 800 ms+6 px guard, seek, marker/conflict/collapse/scroll behavior.
15. **AC15:** Focused tests and the full suite pass without dependency, design or format changes.
