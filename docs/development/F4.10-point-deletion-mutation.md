# F4.10 — Point Deletion Mutation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Maintain path topology when deleting non-initial points. Middle deletion reconnects neighbors with one default; final deletion removes only its incoming path.

## Design and implementation

Reuse existing deletion/synchronization production logic, adding focused regression protection rather than duplicating it. A→B→C becomes default A→C, with new ID/thirds and no merging of old geometry. Preserve unaffected objects/controls, valid selection and current time. Clear deleted point/removed path selection to owner; initial protection and immediate command remain.
