# F7.2 — Cross-Panel Selection Sync

**Status:** Completed in the original MVP development record.

## Requirement and scope

Use one shared selection across scene, timeline and properties for owner, point, path and state keyframe, with at most one subordinate type.

## Design and implementation

Validated selectObject/selectStateKeyframe preserve invalid requests. Point/keyframe selection seeks; path/owner does not. Split group Select from disclosure. Derived intervals carry UI-only sourceStartKeyframeId; local lane handles distinguish hazard projections sharing a source. Edits rebind source identity, deletion falls back to owner. All highlighting checks owner and child IDs. Ordinary seek retains selection.

## Acceptance criteria

1. **AC1:** One shared store source for business selection across panels.
2. **AC2:** Valid owner selection clears child IDs; invalid owner preserves existing state.
3. **AC3:** Header thumbnail/name Select synchronizes scene outline/properties and one group.
4. **AC4:** Select and expand/collapse act independently.
5. **AC5:** Scene switching synchronizes all panels without data/time changes.
6. **AC6:** Scene/timeline point selection aligns identity/details/time.
7. **AC7:** Same-time points on other vehicles do not highlight.
8. **AC8:** Scene path selects owner/group/details without time change.
9. **AC9:** Owned keyframe selection clears point/path and seeks; invalid pairing preserves state.
10. **AC10:** Interval click selects source start keyframe/time and owner, with local clicked-lane handles.
11. **AC11:** Hazard lanes can share underlying keyframe without saved interval ID or mutation.
12. **AC12:** Properties displays track/time/value/keyframe ID plus current-time controls.
13. **AC13:** New type/owner replaces old subordinate visuals/details without stale IDs.
14. **AC14:** Ordinary snapped seek preserves existing selection/model.
15. **AC15:** Pure selection preserves model/reference and saved JSON excludes UI state.
16. **AC16:** Load/clear removes stale details across all panels.
17. **AC17:** Named Select/disclosure and pressed states are accessible without overlap.
18. **AC18:** Five-vehicle desktop/fallback selections remain readable and scrollable.
19. **AC19:** No delete confirmation/new ranges/preview/multi-selection/schema expansion.
20. **AC20:** Selection/sync/isolation/projection/persistence/full checks pass.
