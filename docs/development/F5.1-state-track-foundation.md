# F5.1 — State Track Foundation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Establish typed shared access and discrete time resolution for four vehicle state tracks. This foundation is read-only and adds no keyframe mutations or UI.

## Design and implementation

Map indicator to its enum and brakeLight/headlight/horn to Boolean. getVehicleStateTrack preserves identity; resolveStateKeyframeAtTime/resolveStateValueAtTime return the latest keyframe at or before time, independent of array ordering. Invalid times, malformed/duplicate keyframe times, empty data or no prior state return undefined.

## Acceptance criteria

1. **AC1:** Only four contract-aligned keys with correct value types.
2. **AC2:** Typed track access without any or data copy.
3. **AC3:** Exact-time keyframe/value resolves.
4. **AC4:** Between times use latest prior value without interpolation.
5. **AC5:** Unordered legal input gives identical results without sorting/mutation.
6. **AC6:** Zero/boundaries/between/after-last follow sustained semantics.
7. **AC7:** Negative/non-finite time, empty/missing prior state returns undefined safely.
8. **AC8:** Tracks resolve independently.
9. **AC9:** Reading preserves all animation/editor references.
10. **AC10:** Existing factory defaults resolve without duplicate creation.
11. **AC11:** No new controls/markers/visual state/store mutations.
12. **AC12:** Focused and full checks pass without dependency or design changes.
