# F2.1 — Background Selection

**Status:** Completed; human acceptance passed.

## Requirement and scope

Choose a registered background, persist its asset ID and display it over the logical scene. This was the first editor UI operation that changed animation data. Uploading, clearing backgrounds and vehicle interaction were outside the feature.

## Acceptance criteria

1. **AC1:** List only background-type assets with names and recognizable previews.
2. **AC2:** A project without a background has no selected asset; initial rendering does not write data.
3. **AC3:** Choosing a registered background writes exactly its asset reference, preserving dimensions, objects and editor state.
4. **AC4:** Selected styling derives from the project reference, with no duplicated selection model.
5. **AC5:** Resolve the asset and cover logical coordinates (0, 0, width, height), reserving drawing space above it for objects.
6. **AC6:** Resize scales background and scene together without changing reference or dimensions.
7. **AC7:** Mouse/keyboard activation works with identifiable names and selected state; no runtime/resource errors.
8. **AC8:** Add only background listing, selection and display, without vehicle capabilities.
9. **AC9:** Registry, store, library and scene tests plus regressions, strict checking and build pass.

## Implementation and verification

Type-filtered registry queries supply the library. Native buttons use aria-pressed and visible Selected feedback. An immutable setSceneBackground action updates only the reference; the scene resolves and draws the image. Review fixes addressed truncated selection text and focus outlines causing horizontal overflow.

The original run passed 7 files / 29 tests, strict checking and build. Store isolation, filtering, empty/selected states and full 1600 × 900 image coverage passed. Mouse and Enter activation worked at 1280 × 720, without layout overflow or console warnings/errors. Dependencies and stable design documents were unchanged. The 553.77 kB bundle advisory was non-blocking.

Human acceptance:  covered listing, selected state, rendering, resizing and scope. **Original commit message:** `feat: add background selection`.
