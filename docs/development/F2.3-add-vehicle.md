# F2.3 — Add Vehicle

**Status:** Completed; human acceptance passed.

## Requirement and scope

Add a complete registered vehicle to the scene. Creation must immediately satisfy initial movement/state requirements even though their editing UI is implemented later. This feature allowed one vehicle and did not auto-select it.

## Acceptance criteria

1. **AC1:** With no vehicle, show an accessible Add command with the thumbnail/name.
2. **AC2:** Activating the original Blue car command adds exactly one vehicle with assetId car-blue.
3. **AC3:** A default scene gives one zero-time movement point at (800, 450), with no paths.
4. **AC4:** Each state track has one zero-time keyframe: indicator off, other states false.
5. **AC5:** Vehicle, point and four keyframes have six non-empty, stable, unique IDs.
6. **AC6:** Draw above the background, centered on the stored point using registry geometry, without duplicate position state.
7. **AC7:** Preserve background, dimensions, time and selection.
8. **AC8:** Disable subsequent addition and retain one object; multiple vehicles belong to F7.1.
9. **AC9:** Resize scales the vehicle/background together; stored position remains unchanged.
10. **AC10:** Scene click/drag, properties and timeline editing remain unavailable.
11. **AC11:** Factory, store, library, scene and regression tests, strict checking and build pass.

## Implementation and verification

createVehicleObject centralizes initial data. Production IDs use entity-prefixed crypto.randomUUID; tests inject deterministic IDs. Registry width/height metadata supplies the original 120 × 72 car. Store creation uses the logical center; the library becomes an Add button that shows Added and disables afterward.

The scene uses offsets (60, 36) and the stored point to center the image, with listening disabled. Factory data passes the initial validator.

The original run passed 10 files / 36 tests, strict checking and build. Uniqueness, complete defaults, state isolation, duplicate-add rejection and rendering passed. Browser review at 1280 × 720 showed the vehicle above the intersection at center without overflow or console warnings/errors. Dependencies/design documents were unchanged; the 556.14 kB chunk-size advisory was non-blocking.

The user accepted creation, orientation, scale, single-vehicle limit and resize behavior. car-blue names in this historical record precede the final Sedan/Sport assets.
