# F4.3 — Path Selection

**Status:** Completed in the original MVP development record.

## Requirement and scope

Select a rendered path as the vehicle's exclusive subordinate selection, with highlighting and read-only properties. Selection represents an interval, so it does not seek to a single time.

## Design and implementation

selectPath validates ownership and clears point/keyframe selection, retaining time/data. Scene click/tap uses about 20 px screen hit width and stops bubbling. Selected green#0596696 px and unselected amber 4 px strokes preserve geometry. Properties shows type/path/from/to IDs without ambiguous position inputs. Topology mutations clear removed path selection to object-only and retain valid IDs.

## Acceptance criteria

1. **AC1:** Owned path selection sets object/path and clears incompatible fields.
2. **AC2:** Invalid/misowned references preserve complete state.
3. **AC3:** Selection preserves time/playhead and animation data.
4. **AC4:** Click/tap including hit area selects without background clearing.

11. **AC11:** Removed topology selection clears subordinate IDs; valid paths remain selected.
12. **AC12:** Select/switch/clear preserves animation references.
13. **AC13:** No controls/geometry editing/interpolation/rotation/playback/path deletion.
14. **AC14:** Ownership/events/style/hit-area/properties/cleanup/isolation/regressions pass.
