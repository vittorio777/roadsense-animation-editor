# F6.2 — JSON Serialization

**Status:** Completed in the original MVP development record.

## Requirement and scope

Serialize validated animation data into readable canonical JSON, excluding the complete store and temporary UI state.

## Design and implementation

serializeAnimationProject(unknown) returns serialized/json or invalid/errors. Validate first, rebuild contract-only object fields in fixed order, preserve all arrays and primitive values, use two-space indentation plus one newline. Optional background is omitted when absent. Unexpected canonicalization/stringify failure becomes defensive invalid output rather than propagated exception.

## Acceptance criteria

1. **AC1:** Empty serialization includes schema/identity/scene/empty objects without background.
2. **AC2:** Complete data loses no supported fields/values.
3. **AC3:** Invalid schema/fields/IDs/topology/state/assets returns validation errors without JSON/exception.
4. **AC4:** Output excludes editor time/selection/hover/drag/panels/interval views/actions.
5. **AC5:** Equivalent property insertion orders yield identical strings.
6. **AC6:** Preserve every input array order without normalization.
7. **AC7:** Stable two-space formatting, no trailing spaces and exactly one final newline.
8. **AC8:** Native parse yields equal project accepted by validator.
9. **AC9:** Absent background omitted; present background saves only its asset ID.
10. **AC10:** Unicode/escapes/finite decimals/negative coordinates retain values.
11. **AC11:** Frozen/malformed/repeated calls are pure, safe and deterministic.
12. **AC12:** No browser download/file controls/parser/replacement behavior.
13. **AC13:** Targeted/full checks pass without dependency or design changes.

## Verification and acceptance

Focused verification: 10 tests; validator+serializer 22; the full suite passed 51 files / 358 tests, strict type checking, production build and diff checks passed; 600.21 kB chunk-size advisory. Exact empty output, complete equality, reordered object fields, reversed valid path array, strings/decimals, whole-store rejection and frozen determinism passed. User accepted contract/examples 2026-09-30; no UI change.
