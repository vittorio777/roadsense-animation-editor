# F7.1 — Multiple Vehicles

**Status:** Completed in the original MVP development record.

## Requirement and scope

Remove the single-vehicle restriction using the existing nested model and editing/persistence flow. Each instance must keep independent identity, motion and states.

## Design and implementation

addVehicle appends complete unique instances. Logical center-out positions for first 5 use X50%, 60%, 40%, 70%, 30%, Y50%; additional rows are deterministic/bounded, without format count limits. Addition preserves time/selection. Render all objects/paths, but overlays only active owner. Same-asset ordinals are display-only; IDs remain authoritative. Library shows instance count and reusable Add.

2. **AC2:** Five instances have globally unique nested IDs and valid defaults.
3. **AC3:** First-five placement separates vehicles without moving previous ones.

5. **AC5:** Add remains enabled with accurate count.
