# F5.2 — Indicator Track

**Status:** Completed in the original MVP development record.

## Requirement and scope

Add precise current-time indicator editing with Off/Left/Right/Hazard in properties. Other controls, timeline state authoring and scene light rendering are outside this feature.

## Design and implementation

A radio group resolves the current sustained value. Shared typed mutation updates an exact-time keyframe retaining ID/time or inserts unique sorted data at new time. Same effective value is a complete no-op. A typed updateVehicleStateAtCurrentTime action changes only the target track; selected point/path keeps owner context.

## Acceptance criteria

1. **AC1:** Selected vehicle has exactly four named indicator options.
2. **AC2:** No owner gives no control; its point/path selection retains access.
3. **AC3:** Exact/between/after-last display the resolved value.
4. **AC4:** New default off displays without seek/view writes.
5. **AC5:** Different value at new time creates unique non-empty keyframe.
6. **AC6:** Exact-time change preserves identity/time without duplication.
7. **AC7:** Insertion maintains strict order and other identities.
8. **AC8:** Same effective value preserves full state/track references.
9. **AC9:** Invalid owner/time/key/value atomically rejects safely.
10. **AC10:** Preserve movement, paths, other tracks/vehicles, metadata, time and selection.
11. **AC11:** Seeking only changes resolved display.
12. **AC12:** Mouse/keyboard radio semantics, checked state, focus and fitted text.
13. **AC13:** No other state UI, timeline markers, light preview, flashing or audio.
14. **AC14:** Focused tests and the full suite pass without dependency or design changes.
