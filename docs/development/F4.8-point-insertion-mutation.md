# F4.8 — Point Insertion Mutation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Insert at a new time through existing vehicle-position editing, maintaining chronological adjacency. New connections deliberately use defaults rather than preserving the removed curve shape.

## Design and implementation

Synchronize A→B to A→N, N→B, removing old IDs/controls and creating unique default thirds. Append adds one final segment. Preserve unaffected directed paths/edited controls and valid selections; removed selected path falls back to owner. Same-time edit remains a coordinate update. Unknown baseline/object and non-finite requests are no-ops.

## Acceptance criteria

1. **AC1:** Create a unique point at current time/finite coordinates in chronological order.
2. **AC2:** Insertion replaces old adjacency with its two new links.
3. **AC3:** New cubic paths have distinct unique IDs and default thirds.
4. **AC4:** Do not reuse/subdivide the removed edited controls.
5. **AC5:** Keep unaffected path references/IDs/endpoints/controls/order.
6. **AC6:** Append preserves old data and adds one default link.
7. **AC7:** Exactly n−1 ordered directed paths without orphan/duplicate/reversed links.
8. **AC8:** Removed selected path clears subordinate IDs, retaining owner and insertion time.
9. **AC9:** Unaffected selected path retains highlight/controls.
10. **AC10:** Same-time edit retains point identity and paths array.
11. **AC11:** Renderer/core use new links with finite outputs, not old path.
12. **AC12:** Invalid coordinates/object/baseline preserve complete state.
13. **AC13:** Only new point, affected topology and ancestors change.
14. **AC14:** No new insertion button/path-click, shape-preserving subdivision, time/deletion/preview expansion.
15. **AC15:** Ordering/topology/default/preservation/selection/core/render/invalid/regression checks pass.
