**Status:** Completed in the original MVP development record.

## Requirement and scope

Verify creation, editing and every point mutation against one geometry definition before the state-authoring phase.

## Design and implementation

An integration test reads actual renderer P0/P1/P2/P3 and independently calculates position/derivative/atan 2 at t=0, .25, .5, .75, 1 after creation, control edit, endpoint move, insertion, reorder and deletion. Expected values do not come from production helpers. Inspect topology, IDs, references, finite geometry and defensive boundaries across an in-app desktop matrix.
