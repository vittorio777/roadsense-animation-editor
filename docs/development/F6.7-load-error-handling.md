# F6.7 — Load Error Handling

**Status:** Completed in the original MVP development record.

## Requirement and scope

Explain read, syntax, contract and asset failures through existing loader results while protecting current work. No repair, partial loading, telemetry or separate validation system.

## Design and implementation

presentProjectLoadFailure returns stable title, stage summary and complete deterministic details; read/parse use product wording, assets include paths. Registry failures may arrive via validation while unresolved-assets remains supported. Modal dialog names heading/description, focuses Close, contains Tab/Shift+Tab, closes on Escape/Close and returns focus to Load; backdrop does not dismiss. Local presentation excludes files/rawJSON/project/errors. New load clears old feedback; details scroll within 224 px maximum.

## Acceptance criteria

1. **AC1:** Read failure explains unreadability without raw exception.
2. **AC2:** Invalid syntax has stable message without SyntaxError.
3. **AC3:** Schema/structure failures are listed.
4. **AC4:** Show all invariant/unknown-field errors in original order without repair.
5. **AC5:** Missing/type-mismatched assets identify reference; structured errors include path.
6. **AC6:** All failure stages preserve complete references/JSON/time/selection.
7. **AC7:** Short live toolbar alert remains, details do not expand it.
8. **AC8:** Named/described modal dialog overlays editor.
9. **AC9:** Focus starts/remains on Close; covered editor does not receive it.
10. **AC10:** Close/Escape preserves project and returns focus to Load.
11. **AC11:** Retry/same-file selection runs anew.
12. **AC12:** Successful retry clears old dialog and applies normal replacement.
13. **AC13:** Long details remain readable by internal scrolling without layout expansion.
14. **AC14:** Desktop/fallback keeps dialog/text/Close usable and dismissal restores layout.
15. **AC15:** Valid-load reset/feedback/post-save behavior remains.
16. **AC16:** No repair/migration/partial-load/telemetry/global-notification/round-trip expansion.
17. **AC17:** Adapter/dialog/isolation/regression/full checks pass.
