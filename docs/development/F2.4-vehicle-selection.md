# F2.4 — Vehicle Selection

**Status:** Completed; human acceptance passed.

## Requirement and scope

Click a vehicle to select it and synchronize scene and read-only properties through selection.objectId. Selection is temporary editor state. Dragging and properties editing were separate features.

## Acceptance criteria

1. **AC1:** Clicking selects the vehicle ID and clears movement/path/state selections.
2. **AC2:** Selecting/clearing leaves the project reference and data, background, dimensions and time unchanged.
3. **AC3:** Show a clear, non-interactive outline aligned to stored position and registry dimensions without hiding the vehicle.
4. **AC4:** Properties resolves selection against the project and shows type, registry name and instance ID.
5. **AC5:** Clicking blank scene clears all selection, outline and properties summary.
6. **AC6:** Clicking an already-selected vehicle retains selection without unnecessary state changes.
7. **AC7:** Resizing preserves identity/coordinates and outline alignment.
8. **AC8:** Scene accessible labeling and properties labels communicate selection.
9. **AC9:** No dragging or editable forms; library and timeline behavior remain unchanged.
10. **AC10:** Selection, deselection, outline and properties tests plus regressions, strict checking and build pass.

## Implementation and verification

selectObject/clearSelection update the complete selection consistently. Vehicle click stops bubbling to blank-scene deselection. A non-listening dashed outline derives from the same point and geometry. Properties reads the selected object and has no input/select/textarea controls.

The original run passed 11 files / 40 tests, strict checking and build. Store reference protection, bubbling, outline geometry, properties clearing and accessibility passed. At 1280 × 720 browser selection, reselection and blank-area clearing worked, without console warnings/errors. Dependencies/design documents were unchanged; the 557.86 kB chunk-size advisory was non-blocking.

Human acceptance:  included resize alignment and the read-only boundary. Historical Blue car naming precedes final model variants.
