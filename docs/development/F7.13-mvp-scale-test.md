# F7.13 MVP Scale Test

**Status:** Completed in the original MVP development record.

## Requirement and scope

Verify the specified five-vehicle/60-second data scale with deterministic fixture and existing production modules, separately from final user-workflow acceptance.

## Design and implementation

Builder alternates 3 Sedans/2 Sports with stable IDs, 20 points/19 paths per owner and 20 keyframes on each of 4 tracks:100 points, 95 paths, 400 frames. Times include 0 through 60 and values/coordinates are deterministic; checked-in JSON must equal builder. Sample every integer second, control playback, edit one owner and compare untouched 4, then serialize/parse/validate/resolve/load. Diagnostic timings were measured locally.

## Acceptance criteria

1. **AC1:** Repeated builder yields equal valid data/unique 5 owners without random/time dependence.
2. **AC2:** Exactly 20 ordered unique points/19 adjacent paths per owner, all finite and within 0–60.
3. **AC3:** Exactly 20 unique ordered keyframes per 4 tracks, including 0 and valid values.
4. **AC4:** Both models resolve independently without identity rewriting.
5. **AC5:** Whole validation/resolution succeeds without partial acceptance/mutation.
6. **AC6:** All 61 integer samples and representative quarters compose 5 valid deterministic states without seek writes.
7. **AC7:** Controlled play/pause/end remains monotonic/bounded and correct for all owners.
8. **AC8:** Point/control/state edit obeys rules and preserves other 4/untouched tracks with valid result.
9. **AC9:** Round-trip retains complete edited model and prescribed counts/identities.
10. **AC10:** Repeated math/persistence fits existing timeout and browser remains usable; record local diagnostic timings.
11. **AC11:** Only fixtures/tests/records/media; no new capabilities/schema/optimization. Defects require explicit scope review.
12. **AC12:** Focused/regression/full checks pass.

## Verification and acceptance

- Focused verification: 4 tests; the full suite passed 71 files / 501 tests, strict type checking, production build and diff checks passed; 635.35 kB chunk-size advisory.
- Five validation+61 sample sweeps 13.56 ms; persistence preparation 2.24 ms in recorded local run.
- Browser verification at 1280 × 720 real load showed exact counts/five groups/full range, sought 31.58, played/paused 31.81 without console issues.
- Human acceptance: 2026-10-02.
- Production/dependencies unchanged.
