# F3.6 — Movement Point Selection

**Status:** Completed in the original MVP development record.

## Requirement and scope

Select an existing point from scene or timeline through one temporary selection identity, aligning time and both views. This feature does not modify points or add point-specific editing.

## Design and implementation

Validated selectMovementPoint checks object ownership, sets object/point IDs, clears incompatible fields and aligns time without replacing the project. Timeline diamond buttons use ruler coordinates and stop seek bubbling. Scene circular markers appear only for the selected vehicle, keep fixed display size and use each stored position.

## Acceptance criteria

1. **AC1:** Timeline shows all existing markers at their times.
2. **AC2:** Selected vehicle shows scene markers at stored logical coordinates, stable under scale; unselected vehicle hides them.
3. **AC3:** Timeline marker selects its owner/point and aligns time/playhead.
4. **AC4:** Scene marker selects owner/point and aligns time.
5. **AC5:** Both views highlight the same point and no others.
6. **AC6:** Vehicle-body selection clears subordinate selections.
7. **AC7:** Blank scene clears full selection and properties.
8. **AC8:** Ordinary timeline seek changes time but preserves point selection.
9. **AC9:** Missing/misowned references preserve store/project/time/selection identities.
10. **AC10:** Selecting/clearing preserves serialized animation data and all points/paths/states.
11. **AC11:** Keyboard-operable named timeline markers and readable scene labeling keep layout stable.
12. **AC12:** No point editing, deletion, paths, interpolation or point-specific properties controls.
13. **AC13:** Validation, markers, cross-view clearing, seek preservation and regression checks pass.
