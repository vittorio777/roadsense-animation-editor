# F7.3 Vehicle Deletion

**Status:** Completed in the original MVP development record.

## Requirement and scope

Delete the selected vehicle only after explicit confirmation, removing its nested motion/state data together and synchronizing all views.

## Design and implementation

Typed deleteVehicle returns deleted/invalid. Shared labeled modal locks original target, explains asset/instance/nested removal, defaults focus to Cancel, traps Tab/Shift+Tab, cancels on Escape and restores trigger focus when available. Removing selected owner clears all selection; deleting another retains valid selection. Preserve remaining order/background/time and allow last-vehicle deletion/re-add.

## Acceptance criteria

1. **AC1:** Return explicit typed result.
2. **AC2:** Delete stable ID only and retain other object data/order.
3. **AC3:** Remove nested points/paths/tracks without orphans.
4. **AC4:** Unknown ID preserves complete state.
5. **AC5:** Any selected child of deleted owner clears all IDs.
6. **AC6:** Deleting an unselected owner preserves valid other selection.
7. **AC7:** Preserve metadata/background/other vehicles/current time.
8. **AC8:** Properties command always targets selected owner across child types.
9. **AC9:** Opening confirmation does not mutate and clearly identifies target/consequences.
10. **AC10:** Cancel/Escape preserves all state/views and restores focus.
11. **AC11:** Explicit confirm executes once and cannot delete another owner.
12. **AC12:** Scene/group/lanes/details remove together; others stay editable.
13. **AC13:** Last deletion yields usable empty scene/timeline/properties and allows adding.
14. **AC14:** Accessible modal defaults Cancel and contains keyboard focus.
15. **AC15:** Deleted IDs/data remain absent from valid serialized/reloaded project.
16. **AC16:** Earlier creation/editing/persistence remain stable.
17. **AC17:** Only vehicle deletion gains confirmation; no undo/global shortcut/range/playback expansion.
18. **AC18:** Full tests/strict type checking, build and diff checks pass.
