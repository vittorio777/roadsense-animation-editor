# F5.6 — Initial State Keyframes

**Status:** Completed in the original MVP development record.

## Requirement and scope

Centralize and lock the existing zero-time state defaults in the model factory. No new UI, runtime repair or migration.

## Design and implementation

createInitialVehicleStateTracks produces indicator off and three false states, one zero-time keyframe each with injected IDs for deterministic tests. Vehicle factory delegates to it. Independent instances have fresh objects/arrays. Later edits preserve initial identity; malformed external data remains the persistence validator's responsibility.

## Acceptance criteria

1. **AC1:** Factory contains exactly four tracks.
2. **AC2:** Each has exactly one time=0 keyframe.
3. **AC3:** Defaults are off, false, false, false.
4. **AC4:** Non-empty distinct IDs support injected factory.
5. **AC5:** Vehicle creation delegates without changing runtime format.
6. **AC6:** Adding at nonzero editor time still creates zero-time defaults and retains editor time.
7. **AC7:** Zero-time edit updates existing identity rather than duplicates.
8. **AC8:** Later track edits preserve every zero keyframe and untouched references.
9. **AC9:** Separate factory calls share no mutable track/array/object references.
10. **AC10:** Seek/resolution creates no defaults or writes.
11. **AC11:** Existing properties controls retain behavior with no new UI.
12. **AC12:** Do not silently repair missing tracks/zero frames/duplicate times.
13. **AC13:** Focused tests and the full suite pass without dependency, design or format changes.
