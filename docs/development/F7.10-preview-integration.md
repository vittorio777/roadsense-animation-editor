# F7.10 Preview Integration

**Status:** Completed in the original MVP development record.

## Requirement and scope

Bind resolved lights to explicit typed vehicle model geometry, and make the original top-view body's forward direction recognizable even with all lights off.

## Design and implementation

D002 defines discriminated assets with valid dimensions/forwardDeg/eight lamp anchors/radii/beams. Refresh original 120 × 72 blue+X body with asymmetric front/rear/cabin detail. Generic VehicleVisual consumes composed state+definition only; outer group applies semantic pose, inner−forwardDeg aligns native body/lamps/beams/outline. Non-listening visuals preserve transparent hit area. No dimension guesses, asset-ID branches, extra blink cadence or horn substitutes.

## Acceptance criteria

1. **AC1:** Use typed model and composed values only without re-resolving tracks/guessing/branching.
2. **AC2:** Original body remains identifiable, 120 × 72 blue+X, with direction clear while inactive.
3. **AC3:** World/native transform is shared by body/lights/beams/outline.
4. **AC4:** Off gives four inactive indicators.
5. **AC5:** Left/right activate travel-side front/rear, invariant under rotation.
6. **AC6:** Hazard activates all four corners.
7. **AC7:** Two rear brake lenses switch red state.
8. **AC8:** Front lamps/forward beams switch with headlight; no inactive beams.
9. **AC9:** Exact/before/between/after visuals follow composer, not separate timing rules.
10. **AC10:** Seek/play/pause/resume synchronize pose/all lights and freeze together.
11. **AC11:** Multiple owners retain independent pose/states.
12. **AC12:** Visual nodes do not block editing/selection/drag.
13. **AC13:** Horn persists in composed state without visual/audio/media.
14. **AC14:** Rendering leaves animation/selection unchanged.
15. **AC15:** Scaled/rotated models preserve recognizable parts/handles; alternate test model works without branches.
16. **AC16:** No second production model yet, fallback guessing, automatic blink, horn icon, mode/error expansion.
17. **AC17:** Focused tests and the full suite pass.
