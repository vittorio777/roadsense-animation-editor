# F1.3 — Scene Scaling

**Status:** Completed; human browser acceptance passed.

## Requirement and design

Fit the logical scene into measured panel space while preserving project coordinates. Use a uniform contain scale, capped at 1:

```text
scale = min(availableWidth / sceneWidth, availableHeight / sceneHeight, 1)
displayWidth = sceneWidth * scale
displayHeight = sceneHeight * scale
```

Unmeasured or invalid sizes must not produce invalid Stage values. User zoom/pan and coordinate-based object interaction were outside this feature; panel layout belonged to F1.4.

## Acceptance criteria

1. **AC1 — Fit:** Once measured, display width and height fit available space.
2. **AC2 — Ratio:** Both axes use the same positive scale; a default scene remains 16:9.
3. **AC3 — Coordinates:** Scaling changes display only; saved scene coordinates remain 1600 × 900.
4. **AC4 — Resize:** Available-size changes recalculate scale without clipping or distortion.
5. **AC5 — Cap:** Larger containers use scale 1 and center the scene rather than enlarging it.
6. **AC6 — State:** Loading/resizing does not change project, time or selection.
7. **AC7 — Boundary:** The neutral scene remains without background, objects or zoom/pan controls.
8. **AC8 — Stability:** New/existing tests, strict type checking and build pass without new dependencies.

## Implementation and verification

The pure calculateSceneViewportLayout function computes scale and dimensions. ResizeObserver updates available space; Stage receives display dimensions and equal scales while its internal surface retains logical dimensions. The scene is centered on both axes.

Calculation and observer tests cover resizing and state stability. The original run passed 6 files / 22 tests, type checking and build; dependencies were unchanged. The existing bundle advisory remained.

At 1280 × 720, the canvas measured approximately 652.78 × 367.19; after resize to 1440 × 900 it measured 888 × 499.5. Both ratios were approximately 1.77778 with no overflow. Human acceptance:  confirmed fitting, centering and resize behavior.
