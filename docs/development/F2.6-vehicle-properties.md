# F2.6 — Vehicle Properties

**Status:** Completed; human acceptance passed.

## Requirement and interaction

Provide Position X/Y editing for the selected vehicle while retaining read-only type, asset and instance identity. Inputs keep uncommitted text locally; blur or Enter commits one field, Escape restores it. Parse finite numbers and reuse the dragging bounds; the other coordinate uses the latest saved value.

The original asset's bounds were X 60–1540 and Y 36–864. Rotation, timing and state controls were outside this feature.

## Acceptance criteria

1. **AC1:** Selected properties show identity and X/Y from the zero-time point.
2. **AC2:** Valid X blur/Enter changes only X and updates the scene.
3. **AC3:** Valid Y blur/Enter changes only Y and updates the scene.
4. **AC4:** Out-of-bounds finite input is clamped and displayed within full-vehicle bounds.
5. **AC5:** Empty/non-finite input leaves project reference/data unchanged and restores the saved value.
6. **AC6:** Escape discards uncommitted input without changing animation data.
7. **AC7:** Scene dragging refreshes inputs; property edits refresh image and outline.
8. **AC8:** Retain one point and its ID/time, paths, state tracks, other project fields, selection and time.
9. **AC9:** No selection gives empty guidance without inputs; reselection reads current data.
10. **AC10:** Labeled controls support keyboard editing, Enter and Escape.
11. **AC11:** Identity is read-only; no rotation, time, states, deletion or extra-vehicle controls.
12. **AC12:** Rendering, commits, clamping, rejection/cancel and synchronization tests plus regressions, strict checking and build pass.

## Implementation and verification

React local text state holds drafts; project data remains authoritative. Commits use clampVehiclePosition and updateVehiclePosition. Store changes refresh inputs; display rounds long dragged values to two decimals without reducing saved precision.

The original run passed 13 files / 54 tests, strict checking and build. Commit paths, invalid input, cancel, bounds, selection changes and data invariants passed. Browser review at 1280 × 720 covered Enter/blur, clamping, empty recovery, Escape and scene synchronization; console warnings/errors were absent. Dependencies/design documents were unchanged; the 560.46 kB chunk-size advisory remained.

The user accepted the controls, data protection and feature boundary. **Original commit message:** `feat: add vehicle position properties`.
