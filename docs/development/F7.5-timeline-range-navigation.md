# F7.5 Timeline Range & Navigation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Extend working time to 0–60 while retaining default 10-second density, horizontal navigation and four bounded zoom spans. Navigation must not change data.

## Design and implementation

Visible spans 5 / 10 / 20 / 60; contentWidth=viewportWidth×60/span. Sticky track labels remain while ruler/grid/rows/playhead scroll together. Pointer mappings use full content coordinates, never only visible window. Snap remains 0.1. Full view uses 0.5 visual subdivision/5-second labels; others 0.1/integer labels. Auto-reveal out-of-view time; local scroll/zoom/measurement. Properties max 60. Explicit single-column root grid fixes intrinsic-width measurement feedback.

2. **AC2:** Initial/remounted view starts 0 with span 10.
3. **AC3:** Four single-select spans compute correct content width/labels.
4. **AC4:** Horizontal scroll keeps all time views aligned.
5. **AC5:** Labels/group identities remain sticky.

15. **AC15:** Manual scroll changes no store state or saved JSON.
