# F6.8 — Save/Load Round Trip Test

**Status:** Completed in the original MVP development record.

## Requirement and scope

Verify the complete persistence gate through production modules and real save/load, without adding a parallel implementation.

## Design and implementation

Store actions build representative background/vehicle/multiple points/edited controls/all states. An independent pre-save snapshot is the oracle; serializer→file-like reader→real parser/validator/resolver→ready→loadProject must retain it. Serialize again and compare exact canonical bytes. Cover empty and invalid paths; deterministic fixture supports browser reproduction. This feature added integration tests and verification records.

## Acceptance criteria

1. **AC1:** Build valid representative project with real store actions rather than assembled final data.
2. **AC2:** Save all supported animation fields.
3. **AC3:** Exclude time/selection/feedback/assets metadata/interval projections.
4. **AC4:** Use unmocked production ordered load pipeline.
5. **AC5:** Ready equals independent pre-save snapshot in complete core data.
6. **AC6:** Preserve identities/numbers/states/array order without regeneration/normalization.
7. **AC7:** Runtime assets resolve while project stores only IDs.
8. **AC8:** Restored project equals source and resets time/selection.
9. **AC9:** Second canonical JSON equals first character-for-character including newline.
10. **AC10:** Loading an empty project preserves its empty scene and absent background.
11. **AC11:** Invalid save/JSON/data/assets yield no partial replacement and preserve valid state.
12. **AC12:** Real Save→change/reload→Load restores data/reset/filename.
13. **AC13:** Saving restored project succeeds with equal data.
14. **AC14:** Phase report/index documents baseline, checks, browser matrix/hash/evidence/gate.
15. **AC15:** Success/failure desktop/fallback keeps toolbar/dialog usable with no runtime errors.
16. **AC16:** No migration/repair/autosave/cloud/multiple-vehicle/preview scope.
17. **AC17:** Integration/regression/full checks pass.
18. **AC18:** Human acceptance:  precedes one commit and phase tag.
