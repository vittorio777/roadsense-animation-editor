# F6.1 — Full Project Validation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Extend validation to the complete data contract for unknown input. Keep it pure, deterministic and defensive, without normalization or early persistence UI.

## Design and implementation

Layered validators check schema/known fields, positive dimensions, finite coordinates/nonnegative times, global entity IDs, strict point/keyframe ordering and unique zero defaults, exact directed adjacent paths, state value types and registered assets. Empty scene is valid. Coordinates need not be in scene bounds. Aggregate independent errors in deterministic order; missing parent structure stops child access. isAnimationProject narrows only after full success.

## Acceptance criteria

1. **AC1:** Accept empty/complete valid project with no errors and successful type guard.
2. **AC2:** Reject malformed root/schema/identity/scene/dimensions/background/objects with paths and no exception.
3. **AC3:** Reject unknown/editor-only fields without stripping them.
4. **AC4:** Reject incomplete vehicles, wrong type, empty/missing asset references defensively.
5. **AC5:** Enforce non-empty project-wide unique vehicle/point/path/keyframe IDs.
6. **AC6:** Reject missing/empty/unsorted/duplicate/negative/non-finite movement or missing/duplicate zero point.
7. **AC7:** Check complete cubic path shape, references and finite controls.
8. **AC8:** Reject missing/self/reversed/nonadjacent endpoint relationships.
9. **AC9:** Exactly n−1 paths and one per directed adjacent pair.
10. **AC10:** Require all four tracks with nonempty keyframe arrays.
11. **AC11:** Reject empty IDs, unordered/duplicate/invalid times and missing/duplicate zero states without repair.
12. **AC12:** Indicator enum and Boolean types are strict.
13. **AC13:** Frozen/malformed/repeated input remains unchanged with deterministic safe results.
14. **AC14:** Existing factories/store workflows remain valid without format changes.
15. **AC15:** No serialization, parsing, file controls, replacement or error UI.
16. **AC16:** Targeted/full checks pass without dependency or design changes.
