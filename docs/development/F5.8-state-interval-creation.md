# F5.8 — State Interval Creation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Create finite intervals by dragging empty lanes, using keyframes as the sole saved representation. Existing-interval moving/resizing/deletion belong to F5.9.

## Design and implementation

Require hold≥800 ms and horizontal movement≥6 px; until then retain ordinary seek. Preview is local until mouseup and uses 0.1 snapping in either direction. Boolean[start, end) writes true and restores original outside state. Indicator mutates one side while preserving all opposite-side transitions. Normalize unique ordered boundaries, preserve reusable IDs, reject occupied target lane and safely merge adjacent spans.

## Acceptance criteria

1. **AC1:** Threshold starts lane-colored snapped preview without pre-release writes.
2. **AC2:** Both drag directions normalize to identical finite start/end.
3. **AC3:** Boolean range becomes true; outside state unchanged.
4. **AC4:** Indicator edits only the chosen side.
5. **AC5:** Opposite-lane overlap becomes hazard without losing single-side portions.
6. **AC6:** Preserve resolved state outside the range, including existing transitions.
7. **AC7:** Reuse retained boundary identity without duplicate times.
8. **AC8:** Remove repeated values; merge adjacent active spans with strict unique order.
9. **AC9:** Positive overlap in target lane rejects whole state; adjacency is allowed.
10. **AC10:** Below threshold/zero/invalid owner/lane/time/track/ID creates no partial data or errors; ordinary seek remains.
11. **AC11:** Explicit drag to visible end may author end keyframe; visual clipping alone may not.
12. **AC12:** Only target owner/track changes; preserve other data/time/selection references.
13. **AC13:** Existing interval press does not start creation or add editing yet.
14. **AC14:** Ruler/playhead/markers/collapse/seek keep previous behavior.
15. **AC15:** Focused tests and the full suite pass without dependency, design or format changes.

## Verification and acceptance

- Focused verification: 18 tests; the full suite passed 46 files / 317 tests, strict type checking, production build and diff checks passed.
- Browser short Horn press sought≈2.9 without creation; held Brake drag≈2–4 created on release.
- Human acceptance: 2026-09-30 followed tuning the 800 ms+6 px accidental-creation guard.
- Stable documents, dependencies and format were unchanged; existing bundle advisory remained.
