# F3.1 — Timeline Ruler

**Status:** Completed in the original MVP development record.

## Requirement and scope

Create the default linear 0–10-second ruler as the foundation for timeline editing. This feature is display-only; seeking, snapping interaction, tracks and editing belong to subsequent MVP tasks.

## Design and implementation

Generate 101 positions at 0.1-second intervals, including both ends: major ticks each second, medium ticks at remaining half-seconds, minor ticks elsewhere. Map leftPercent = ((time - start)/(end - start)) × 100. Eleven labels use edge alignment to avoid clipping. The deterministic display model is not saved.

## Acceptance criteria

1. **AC1:** Replace the timeline placeholder with a real ruler.
2. **AC2:** Include labels at 0–10 seconds and every integer between.
3. **AC3:** Use nonduplicated major/medium/minor tick hierarchy.
4. **AC4:** Map 0 / 5 / 10 seconds to start/middle/end with equally spaced time.
5. **AC5:** At three desktop sizes, relayout without clipped labels, height changes or panel jumps.
6. **AC6:** Below minimum, retain the full workspace ruler accessible by page scrolling.
7. **AC7:** Expose a 0-to-10-seconds name without 101 redundant focus targets.
8. **AC8:** Rendering/resizing preserves project reference, time and selection; no persisted ruler model.
9. **AC9:** Clicks remain inactive without playhead, readout or editing controls.
10. **AC10:** Preserve scene, properties, vehicle and library behavior and available workspace.
11. **AC11:** Tick generation/classification/mapping, rendering, accessibility and state/regression tests, strict checking and build pass.

## Verification and acceptance

- Original run: 15 files / 60 tests, strict checking and build passed.
- At 1280 × 720 the full ruler, endpoint labels and tick hierarchy were visible without panel changes.
- The existing >500 kB chunk-size advisory remained non-blocking.
- The user accepted spacing, labels, inactive click behavior and scope.
