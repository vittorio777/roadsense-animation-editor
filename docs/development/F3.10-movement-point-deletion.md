# F3.10 — Movement Point Deletion

**Status:** Completed in the original MVP development record.

## Requirement and scope

Delete non-initial points while preserving the zero-time invariant and consistent views. At this stage Delete point was immediate; confirmation was deliberately reserved for F7.4.

## Design and implementation

Typed results are deleted, protected-initial and invalid. Delete by owner/point ID, keep time unchanged, retain owner selection and clear subordinate selection only if its point is deleted. Unselected deletion retains selection references. Vehicle position falls back to the nearest earlier remaining point, and shared project state removes both markers.

## Acceptance criteria

1. **AC1:** Return explicit deletion/protection/invalid result.
2. **AC2:** Remove only the target non-initial ID, preserving other point data.
3. **AC3:** Zero-time deletion is a full-store no-op.
4. **AC4:** Missing/misowned requests preserve store references.
5. **AC5:** Deleting selected point keeps owner and clears point/path/keyframe selection.
6. **AC6:** Deleting unselected point preserves selection references.
7. **AC7:** Keep current time; resolve prior remaining point at the deleted time.
8. **AC8:** Remove the marker from scene and timeline together.
9. **AC9:** Selected nonzero properties offers immediate Delete point and returns to vehicle properties.
10. **AC10:** Zero-point/object-only properties offers no point delete command.
11. **AC11:** Keep ordering, zero point, empty phase-stage paths, states/identity/metadata and validator acceptance.
12. **AC12:** Creation/editing/conflicts continue without stale selection or duplicates.
13. **AC13:** No confirmation, topology, undo/redo, vehicle deletion or keyboard shortcut.
14. **AC14:** Deletion/protection/cleanup/synchronization/validation and regressions pass.

## Verification and acceptance

- Original run: 24 files / 122 tests, strict checking and build passed.
- Store isolation, references, validator, both marker removals and fallback at unchanged time passed.
- Browser pre-check showed immediate deletion; the user accepted removal, selection fallback, protection and existing edits on 2026-09-29.
- No visible runtime error.
