# F7.4 Movement Point Delete Confirmation

**Status:** Completed in the original MVP development record.

## Requirement and scope

Add confirmation to existing point deletion, reusing established protection and path reconnection instead of changing them.

## Design and implementation

Reuse shared ConfirmationDialog with a single discriminated vehicle/point target so only one modal opens. Lock vehicle ID, point ID/time when opening, explain reconstruction and confirm through the unchanged deletion action. Cancel restores trigger; confirmed removal may remove that trigger. Stale targets remain safe invalid no-ops.
